Software Engineering

About This Repository

This repository contains my practical activities, exercises, and learning materials for the Software Engineering course.

Course Focus

* Software development environments
* Requirements management tools
* Software design and modelling
* Integrated Development Environments (IDEs)
* Version control systems
* Git and GitHub
* Collaborative software development
* Issue tracking and documentation
* Continuous Integration (CI)

Purpose

The purpose of this repository is to practise software development concepts, understand version control, and develop practical skills in collaborative software engineering.
